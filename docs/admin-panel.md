# Панель управления BYgram

Точка входа — `api/admin.php`. Панель на Astryx объединяет обзор, значки, публикацию APK, список администраторов, интеграции и «Пламя». Вход через Telegram доступен владельцу и администраторам. Состав администраторов меняет владелец.

## Пользователи

Откройте `api/admin.php?page=users`. В одной строке отображаются модель устройства, версия BYgram, версия Android API и даты первого и последнего запуска. Один Android-профиль считается одним устройством, даже если в BYgram открыто несколько аккаунтов. Учёт начинается с версии, которая отправляет отметку о запуске. Публичный `api/users-count.php` возвращает только суммарное число. При отключении сбора статистики в клиенте запись устройства удаляется из списка и счётчика после синхронизации.

Нужна миграция `server/activity-api/migrations/20261117_client_devices.php`.

## Бета-версия

Откройте `api/admin.php?page=beta`, выберите APK, укажите версию, код сборки, номер релиза BYgram из настроек приложения и новое имя файла с префиксом `BYgram-beta-`, затем опубликуйте. Номер релиза BYgram должен расти при публикации новой сборки. Панель записывает номер, размер и SHA-256 в `api/beta.json`. Публичная страница загрузки и проверка обновлений в приложении используют этот файл.

## Пламя

Откройте `api/admin.php?page=flames`. В списке доступны сохранённые серии, включая угасшие. Серия скрыта из списка, поиска, сводки и редактирования, если хотя бы один участник отключил сбор статистики и синхронизировал это состояние. Поиск работает по Telegram ID, имени или username любого участника. Фильтр показывает горящие серии, ожидающие обмена сегодня или угасшие. Даты относятся к московскому календарю.

Через «Изменить» можно поправить число дней, дату последнего засчитанного дня, сведения о предыдущей серии и остаток восстановлений на текущий месяц. Чтобы очистить предыдущую серию, укажите ноль дней и пустую дату. После сохранения данные увидят оба участника при следующем обновлении состояния. Если серия изменилась со времени открытия формы, откройте актуальную запись и повторите правку.

## Сборка сайта

Из `server/site` выполните `npm run build`. Точка входа панели — `src/admin.jsx`. PHP загружает `assets/admin-console.js` и `assets/admin-console.css` из сборки. Вместе с ними загружайте импортируемые модули из `dist/assets`, перечисленные в манифесте Vite. Сервер использует существующую таблицу `chat_flames` из миграции «Пламени».
