# BYgram Android на основе exteraGram

Ветка миграции начинается с исходников exteraGram 13.2.2. Основной Android-модуль — `TMessagesProj`.
Приложение сохраняет идентификатор `com.bygram.mobile`. Существующую установку можно обновить пакетом с тем же сертификатом подписи и большим кодом версии.

## Настройки и данные

Темами, паками иконок и внешним видом управляет меню настроек exteraGram. Плагины формата `.plugin` устанавливаются через раздел «Плагины» сборки `full`. Прежний каталог и форматы `.byplugin` и `.byicons` отсутствуют в этой ветке. Существующие данные этих систем при обновлении автоматически не удаляются.

Пункт «Настройки BYgram» расположен сразу под пунктом «Настройки exteraGram» в общих настройках приложения. Он открывает отдельный экран с режимом призрака, «Шпионом», скрытыми и защищёнными чатами, обменом активностью, просмотрами профиля, разделом «Другое» и ссылками проекта BYgram. Параметры и локальные данные используют прежние ключи BYgram. Папки сверх лимита Telegram и дополнительные закрепления хранятся на текущем устройстве. «Пламя» использует текущий API BYgram и находится в меню личного чата.

Сбор статистики включён по умолчанию. Его можно отключить в «Настройки BYgram» → «Другое». После синхронизации устройство исключается из общего счётчика, а серии с участием подтверждённых аккаунтов на этом устройстве скрываются в админ-панели. Изменение для аккаунта отправляется после авторизации BYgram. Серии в чатах сохраняются.

В «Кастомизации» можно настроить фон профиля, сворачивание элементов списка чатов и снег. Публикация фона требует подтверждённого аккаунта BYgram. Размещение фона в профиле определяется настройкой его владельца.

Огонёк в группе учитывает дни, когда написали минимум два разных участника. Общая серия доступна в группах, где бот BYgram может подтвердить членство через Telegram. Для надёжной проверки бот должен быть администратором группы.

## Сервер и сайт

Исходники сайта в `server/site` собираются командами `npm ci` и `npm run build`. PHP API в `server/activity-api` сохраняет авторизацию, сессии, обмен активностью, просмотры профиля, «Пламя», статистику и публикацию APK. Для существующей базы нет миграции, удаляющей таблицы старого каталога.

## Проверка перед выпуском

Для проверки собирайте один универсальный APK Full Debug задачей `:TMessagesProj:assembleFullAfatDebug`. Он включает `armeabi-v7a` и `arm64-v8a`, а также Python и систему плагинов.

На тестовом устройстве проверьте обновление поверх подписанного BYgram, видимость и ввод пароля для защищённых чатов, фильтрацию поиска и уведомлений, чтение архива «Шпиона» и работу локальных папок после перезапуска. Включите плагин exteraGram из файла `.plugin` и проверьте его загрузку после перезапуска. Проверьте вход в BYgram через Telegram и восстановление «Пламени» в тестовом личном чате.
